# 주식 매매 관리 장부

`주식매매장부.html` 파일을 **더블클릭**하면 브라우저에서 바로 열립니다. 설치·로그인·인터넷 연결이 필요 없습니다.

## 매일 하는 일 (30초)
1. 증권사 체결내역을 복사해 **붙여넣기** 칸에 넣는다. (또는 입력 칸에 직접 입력)
2. 맨 위 **✅ 오늘 마감 (한 번에)** 버튼 한 번.

버튼 하나로 다음이 한꺼번에 처리됩니다.
- 붙여넣은 내역 반영 → 수수료·세금 자동 계산
- 평균단가(이동평균법) 갱신, 매도 건별 실현손익 계산
- 당일·이번 달·올해 누적 실현손익, 보유 현황 리포트 생성 (📋 복사 버튼으로 카톡·메모에 붙여넣기)
- 백업 파일(.json) 자동 저장

## 붙여넣기 형식
한 줄에 한 건. 탭·쉼표·공백 구분 모두 가능합니다.

    2026-10-23  KODEX 미국고배당다우존스  매수  100  12,500
    20261023 삼성전자 매도 4 75000

날짜 생략 시 오늘, 수량 뒤에 단가가 오면 됩니다. 읽지 못한 줄은 따로 알려 줍니다.

## 꼭 알아둘 점
- **데이터는 이 브라우저 안에만 저장**됩니다. 브라우저 기록 삭제나 PC 교체 시 사라지므로 백업(.json)을 OneDrive 등 클라우드 폴더에 두세요.
- 수수료율(0.015%)·거래세(주식 0.20%, ETF 0%)는 **임시 기본값**입니다. 설정 탭에서 본인 증권사 실제 값으로 고치고, 체결내역의 실제 금액과 한 번 대조해 보세요.
- 보유보다 많이 매도한 건(입력 누락)은 손익에서 제외하고 ⚠로 알려 줍니다.
- 현재가는 직접 입력합니다(자동 시세 조회 없음). 해외 직접투자, 양도세, 배당소득세, 금융소득종합과세·건보료 영향은 계산하지 않습니다.
- 엑셀 사용 시: **📊 엑셀(CSV) 저장** 버튼으로 전체 거래를 내보낼 수 있습니다.
