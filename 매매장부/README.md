# 주식 매매 관리 장부

`주식매매장부.html` 파일을 **더블클릭**하면 브라우저에서 바로 열립니다. 설치·로그인·인터넷 연결이 필요 없습니다.
기존 엑셀 `주식_포트폴리오_관리_및_매매일지.xlsx`(종합위탁_보유주식 · ISA · 스윙_매매일지)의 열 구성에 맞춰 만들었습니다.

## 처음 한 번: 현재 보유 종목 올리기
1. **보유 현황** 탭 맨 아래 "기초 보유 등록"
2. 엑셀 보유주식 시트에서 종목 행을 복사해 붙여넣기 → 계좌 선택 → **기초 보유로 등록**
   (종목명 · 섹터 · 보유수량 · 매입단가 · 현재가 순으로 읽고 합계·머리글 줄은 건너뜁니다)
3. 표에서 종목별 **1차 목표가 · 손절 기준가 · 대응 전략**, 계좌별 **예수금**을 입력

## 매일 하는 일
1. 증권사 체결내역을 **붙여넣기** 칸에 넣기 (또는 입력 칸에 직접 입력 — 진입근거·손절가·목표가·복기 포함)
2. 보유 현황 탭에서 **현재가** 입력 (Tab 키로 다음 칸으로 이동)
3. 맨 위 **✅ 오늘 마감 (한 번에)** 버튼

버튼 한 번에 처리되는 것
- 붙여넣은 체결 반영, 수수료·세금 자동 계산
- 계좌·종목별 평균단가(이동평균법) 갱신, 매도 건별 실현손익
- 당일·이번 달·올해 누적 실현손익, 계좌별 현황, 손절선 이탈·목표가 도달 알림
- 매수 건의 원칙 점검 (손절가 미입력 / 손익비 1:2 미만)
- 📋 복사로 카톡·메모에 붙여넣을 리포트, 백업 파일(.json) 자동 저장

## ISA 예상 분배금
**보유 현황** 탭의 "예상 분배금" 표에서 종목별로 **배당 주기**와 **연간 예상 배당률(%)**을 입력하면 엑셀 ISA 시트와 같은 방식으로 계산합니다.
- 예상 연 배당금 = 평가금액(현재가 미입력이면 매입금액) × 연간 예상 배당률, 예상 월 분배금 = 연 배당금 ÷ 12
- ETF와 ISA 계좌 종목이 표에 나옵니다. 합계 줄에 월·연 합계와 가중평균 배당률이 나옵니다.
- ISA 계좌 합계는 **비과세 한도**(설정 탭, 기본 200만원)와 비교해 한도 대비 %와 초과분의 예상 분리과세액(기본 9.9%)을 보여 줍니다.
- 기초 보유 등록에서 ISA 시트 행을 붙여넣으면 `월배당 6.50%` 부분을 읽어 배당 주기·배당률도 채웁니다.
- 마감 리포트와 보유현황 CSV(배당 주기·배당률·월 분배금·연 배당금 열 추가)에도 들어갑니다.
- 분배금만 단순 추정한 값입니다. ISA 내 매매손익 통산, 커버드콜 분배금 변동, 원천징수 시점은 반영하지 않습니다. 한도·세율은 엑셀 기준 값이니 본인 유형(일반형/서민형)에 맞게 설정에서 확인하세요.

## 매수 입력 중 실시간 경고 (체크리스트 반영)
- Rule 1: 손절 기준가가 비어 있음
- Rule 3: 손익비(목표가-단가)/(단가-손절가)가 1:2 미만
- Rule 6: 보유 평단보다 낮은 가격의 추가 매수(물타기)

막지는 않고 경고만 표시합니다.

## 붙여넣기 형식 (체결내역)
한 줄에 한 건. 탭·쉼표·공백 구분 모두 가능합니다.

    2026-10-23  종합위탁  삼성전자  매도  4  285,500
    20261023 ISA TIGER 미국배당다우존스 매수 10 14500

줄 안에 `종합위탁`·`ISA`가 있으면 그 계좌로, 없으면 입력 칸의 계좌로 들어갑니다. 수량 뒤에 단가가 오면 됩니다.

## 엑셀로 돌려놓기
- **📊 매매일지 CSV**: 엑셀 `스윙_매매일지` 시트와 같은 열 순서 (거래일자·계좌·종목명·매매구분·수량·단가·…·청산일자·청산단가·실현손익·수익률·복기)
- **📊 보유현황 CSV**: 엑셀 `보유주식` 시트와 같은 열 순서

## 꼭 알아둘 점
- **데이터는 이 브라우저 안에만 저장**됩니다. 브라우저 기록 삭제나 PC 교체 시 사라지므로 백업(.json)을 클라우드 폴더에 두세요.
- 수수료율(0.015%)·거래세(주식 0.20%, ETF 0%)는 **임시 기본값**입니다. 설정 탭에서 실제 값으로 고치세요.
- 엑셀 매매일지는 수수료·세금을 빼지 않고 손익을 계산하므로, 이 장부의 실현손익은 엑셀보다 비용만큼 적게 나옵니다.
- 보유 수량보다 많이 매도한 건(입력 누락)은 손익에서 제외하고 ⚠로 알려 줍니다.
- 현재가는 직접 입력합니다(자동 시세 조회 없음). 현재가 미입력 종목은 매입금액으로 평가합니다.
- 아직 반영하지 않은 엑셀 항목: 대시보드 코멘트, 투자원칙 체크리스트 시트(매수 경고에 일부만 반영). 실제 받은 분배금 기록도 아직 없습니다.
- 해외 직접투자, 양도세, 배당소득세, 금융소득종합과세·건보료 영향은 계산하지 않습니다.
