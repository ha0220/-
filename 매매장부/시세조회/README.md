# 시세 조회 도우미 (선택 사항)

장부의 **현재가를 직접 붙여넣는 대신**, 이 PC에서 도우미를 한 번 실행하면 보유 종목의 현재가를 조회해 파일로 만들어 줍니다. 그 파일을 장부의 **📂 시세 파일 불러오기**로 고르면 미리보기 → 반영까지 이어집니다.

> ⚠ **검증 상태를 먼저 읽어 주세요.** 이 도우미는 개발 환경에서 외부 접속이 막혀 있어 **실제 시세 서버로는 시험하지 못했습니다.** 백업 읽기·보유 종목 계산·종목코드 관리·출처 전환·파일 출력은 가짜 응답으로 시험했지만, 네이버 증권·야후 파이낸스의 **실제 응답 형식은 제가 아는 형식을 가정**한 것이라 이 PC에서 안 될 수 있습니다. 처음에는 **진단**(아래 2번)부터 실행하세요. 안 되면 출력 내용을 알려 주시면 맞춰 고치고, 그동안은 장부의 "현재가 붙여넣기"를 쓰면 됩니다.

## 준비 (한 번만)
- **파이썬 3.8 이상**이 필요합니다(추가 설치 없음). Windows는 https://www.python.org/downloads/ 에서 설치할 때 **"Add python.exe to PATH"** 를 체크하세요. Mac은 `python3`가 있으면 됩니다.
- 이 `시세조회` 폴더를 통째로 PC의 아무 곳에 복사합니다(예: 문서 폴더).

## 사용 순서
1. **장부에서 백업 저장**: 장부의 **💾 백업 저장**을 누르거나 **오늘 마감**을 하면 `매매장부_백업_날짜.json`이 다운로드됩니다. 도우미는 다운로드·바탕화면·문서 폴더에서 **가장 최근 백업**을 찾아 보유 종목을 읽습니다.
2. **진단(처음 한 번)**: `시세조회_진단.bat`(Mac은 `시세조회_진단.command`)을 더블클릭합니다. 삼성전자로 각 시세 출처와 종목코드 검색이 되는지 보여 줍니다. 한 곳 이상 ✅면 사용할 수 있습니다.
3. **조회**: `시세조회.bat`(Mac은 `시세조회.command`)을 더블클릭합니다. 종목별 현재가가 나오고 `시세결과/시세_최신.txt`가 만들어집니다.
4. **장부에서 불러오기**: 오늘 입력 탭 → **현재가 붙여넣기** → **📂 시세 파일 불러오기** → `시세결과/시세_최신.txt` 선택 → 미리보기 확인 → **현재가 반영** (또는 **오늘 마감**).

터미널에서 직접 쓰려면: `python fetch_prices.py [백업.json] [--names "삼성전자,KODEX 200"] [--source naver|yahoo] [--out-dir 폴더] [--test]`

## 종목코드
- 시세는 종목코드로 조회합니다. 종목명을 **네이버 검색으로 자동 변환해 `종목코드.csv`에 저장**하고, 다음부터는 저장된 코드를 씁니다.
- 이름이 **정확히 같은 종목이 하나일 때만** 받아들이고, 비슷한 이름으로 추측하지 않습니다(엉뚱한 종목 시세가 들어가는 것을 막기 위해).
- 못 찾은 종목은 `종목코드.csv`에 `종목명,` 줄로 적어 두니, **쉼표 뒤에 6자리 코드만 채우고** 다시 실행하세요. (`종목코드.csv`는 엑셀·메모장으로 열 수 있습니다. 종목명의 공백·대소문자 차이는 무시합니다.)

## 시세 출처와 동작
1. **네이버 증권 실시간(일괄)** → 2. **네이버 모바일(개별)** → 3. **야후 파이낸스**(`.KS` 후 `.KQ`) 순서로 시도하고, 앞에서 실패한 종목만 다음 출처로 넘어갑니다. 결과 옆에 어느 출처에서 받았는지 표시됩니다.
- 모두 **공식 서비스가 아닌 비공식 주소**입니다. 개인 용도로 소량만 조회하도록 요청 사이에 간격을 두지만, 서비스 약관과 주소·형식 변경은 사용자 책임이며 어느 날 갑자기 안 될 수 있습니다.
- 장중에는 실시간에 가까운 값, 장 마감 후에는 종가가 나옵니다(출처에 따라 약간의 지연이 있을 수 있음).
- **외부로 보내는 정보**: 종목명(코드 검색)과 종목코드뿐입니다. 수량·매입가·계좌·예수금은 **보내지 않습니다**(백업 파일은 이 PC에서만 읽습니다).
- 결과 파일은 `종목명<탭>현재가` 줄이며, 장부 "현재가 붙여넣기"가 읽는 형식 그대로입니다. 장부 미리보기에서 변동이 30% 이상인 종목은 ⚠로 알려 줍니다.

## 문제가 생기면
| 증상 | 확인 |
|---|---|
| "백업 파일을 찾지 못했습니다" | 장부에서 백업 저장 후 다시 실행, 또는 `python fetch_prices.py 백업파일경로` |
| 진단이 모두 ❌ ("접속 실패") | 인터넷 연결, 회사·보안 프로그램의 외부 접속 차단 여부. 안 되면 장부의 "현재가 붙여넣기" 사용 |
| 진단이 "HTTP 403/429" | 접속이 막히거나 요청이 많다는 뜻. 잠시 후 다시, 또는 `--source yahoo` 등 다른 출처 지정 |
| 코드 검색만 ❌ | `종목코드.csv`에 `종목명,코드`를 직접 적기 |
| 응답 형식이 다르다는 메시지 | 출처의 형식이 바뀐 것입니다. 진단 출력을 알려 주세요 |
| 일부 종목만 실패 | 종목명이 증권사 표기와 다르거나 코드가 틀린 경우. `종목코드.csv`의 코드를 확인 |

종료 코드: 0 전부 성공 / 1 하나도 못 가져옴 / 2 백업·종목 없음 / 3 일부만 성공(코드 미확인 포함).
