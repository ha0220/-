# 클로드에게 유튜브를 보여주는 세 가지 설정 — 따라 하기 정리

기준: 업로드 2026-09-21 · 확인일 2026-10-22 · 길이 39초(쇼츠) · 채널 파인튜닝 제작소 · https://www.youtube.com/watch?v=tYje8O-JdcU
길: **말**은 A길(유튜브 자막 파일) + 제미나이 2종이 소리로 받아 적은 것. **화면**은 B길(제미나이 2종의 판독).
영상 파일은 받지 못했다(영상 서버가 403으로 막음). 그래서 **내가 직접 눈으로 본 장면은 없다.**
자막은 **자동 생성**(수동 자막 없음). 제미나이 모델: `gemini-3.5-flash`, `gemini-3-flash-preview` (서로 다른 모델 둘이 같게 읽은 것만 `[일치]`).

## 결론

- **이 영상이 알려 주는 것:** 클로드가 유튜브 영상의 말(자막)과 화면을 읽게 하는 도구를 `npx --yes reborn-ytlearn` 한 줄로 깔고, 선택으로 제미나이 키를 받고, 클로드 코드에 담당자를 짜 달라고 하는 3단계.
- **따라 해도 되나: 확인 후 가능.** 설치 명령과 순서는 믿을 만하다. 다만 영상이 보여 주는 **버전 숫자와 가격은 읽을 수 없거나 틀렸다.** 영상 숫자 말고 `--check` 결과와 공식 화면을 보라.
- **가장 큰 위험:** ① 자동 자막만 믿으면 "키값은 **영원**"으로 읽힌다(실제는 **0원**). ② `npx`는 외부 코드를 실행한다. ③ 영상은 끝에서 유료 스킬팩으로 이어지는 홍보물이다 — 따라 하는 데 필요 없다.

## 4. 확인 못 한 것

- **도구 버전 숫자** (약 00:03): 판독 4번이 모두 다르다. 영상에서는 알 수 없다.
- **화면의 세세한 글자** (로그의 샘플 영상 주소 등): 판독마다 다르다. 따라 하는 데 필요 없어 확정하지 않았다.
- **제미나이 키를 어디에 저장하나:** 영상은 보여 주지 않는다. (가이드: `.env`에 `GEMINI_API_KEY=...`, 영상 밖 확인)
- **내가 직접 본 장면:** 없음. 화면 항목은 모두 제미나이의 판독이다.

## 5. 따라 할 순서

준비물: Node.js(`npx` 용), 클로드 코드, `yt-dlp`, `ffmpeg`. 영상은 이 준비물을 **말로도 화면으로도 설명하지 않는다**(버전 표만 스침). 윈도우 화면으로 보이지만(`C:\AppData\...`) 영상이 OS를 말하지는 않는다 `[추정]`.

1. **(영상 밖) 먼저 재 본다.** 터미널에서 `npx --yes reborn-ytlearn --check`
   - 아무것도 깔지 않고 `ffmpeg`·`yt-dlp`가 있는지, 스킬이 이미 있는지만 본다. 버전 숫자는 영상 말고 **이 결과를 믿는다.**
   - 근거 `[영상 밖 확인]` · 성공 신호: 있다/없다가 나온다.
2. **(영상 밖) 없는 것을 깐다.** `pip install -U yt-dlp`, 윈도우 `winget install ffmpeg`, 맥 `brew install ffmpeg`
   - 설치기는 둘이 없어도 스킬은 깔지만, 돌릴 때 필요하다. 오래된 `yt-dlp`는 유튜브가 바뀌면 깨지니 최신으로.
3. **(00:14) 스킬을 깐다.** `npx --yes reborn-ytlearn` — 근거 `[화면만]` + 영상 밖 확인
   - ⚠ `npx --yes`는 확인 없이 외부 패키지를 받아 실행한다. 이 패키지(v1.0.1)의 `cli.mjs`를 읽어 보니 **스킬 3개를 `~/.claude/skills/`에 복사하고, 끝에 스킬팩 광고 링크를 출력할 뿐 네트워크 호출은 없었다.** 의존성도 `postinstall` 훅도 없다. 다만 이후 버전이 같다는 보장은 없다. 불안하면 `--dry-run`을 먼저.
   - 성공 신호: "붙었습니다 yt-transcript / yt-frames / ytlearn-ko-guide", "돌아갑니다". 안 될 때: 권한 확인, `--force`로 덮기, `--local`로 현재 폴더에 놓기.
4. **(00:18~00:20) 확인하고 클로드 코드를 한 번 껐다 켠다.** `~/.claude/skills/`에 폴더 3개가 있는지.
   - 근거 `[일치]`. **"다시 켜야 잡힌다"는 말은 영상에 없다** (설치기 안내, 영상 밖 확인).
5. **(00:21~00:24) 선택: 제미나이 키.** `aistudio.google.com` → "+ Create API key" — 근거 `[일치]`
   - 키가 필요한 때: 영상 하나를 통째로 이해시키고 싶을 때, 또는 유튜브에 직접 접속이 안 되는 환경. 스킬만으로 자막·장면 읽기는 된다.
   - ⚠ 키는 `.env` 한 곳에만 두고, 대화창·코드에 붙이지 않는다.
   - 제한 `[화면만]`: 공개 영상만, 무료는 하루 8시간 분량. 가격·한도·사용 가능 모델은 바뀌고 계정마다 다르다(이 세션에서도 `pro` 모델은 무료 한도 0, 일부 모델은 신규 사용자에게 404였다).
6. **(00:27~00:29) 담당자를 짜 달라고 한다.** 클로드 코드(`claude`)에 입력: `유튜브로 배우는 담당자 짜줘 절차·검수 포함` — 근거 `[화면만]`
   - **이 저장소에는 이미 `youtube-learner` 담당자가 있다.** 이 저장소에서는 건너뛰어도 된다.
   - 먼저 직접 확인: 영상 속 문장은 한 줄이다. 영상 밖 가이드는 「말과 화면을 대조하고, 말로만 한 것과 화면에 있는 것을 가르고, 마지막에 따라 할 순서를 남긴다」까지 구체적으로 적게 한다.
7. **쓴다.** 담당자에게 유튜브 주소를 준다. 성공 신호: 말/화면/순서가 갈라진 보고서가 나온다.
8. **건너뛴다:** 댓글에 "유튜브" 남기기(가이드는 1번에서 이미 깔린다), 스킬팩 구매(8,900원, 없어도 된다 — 설치기 코드에도 "안 사셔도 됩니다"라고 적혀 있다).

## 6. 영상 밖에서 확인할 것

- 도구 버전: `npx --yes reborn-ytlearn --check`의 출력
- 제미나이 한도·가격: `aistudio.google.com`의 rate-limit 화면 (영상의 "하루 8시간"은 영상 업로드 시점 기준)
- 스킬팩 가격·내용: 사려는 경우에만, 결제 페이지에서
- 자동 자막의 숫자·고유명사(이 영상에서는 "영원", "재미나이", "운서로"가 틀렸다)
