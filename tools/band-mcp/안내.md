# 네이버 밴드 커넥터 만들기 (처음 하는 분용)

네이버 검색 커넥터와 같은 방식입니다. **Cloudflare Worker를 하나 더 만들고**, 그 주소를 claude.ai 커넥터로 연결합니다.

연결되면 Claude가 할 수 있는 일:
- `band_list`: 내 밴드 목록 보기
- `band_posts`: 밴드 글 읽기 (최신순, 최대 20개씩)
- `band_comments`: 글의 댓글 읽기
- `band_write_post`: 밴드에 글 올리기. **`WRITE_BANDS`에 적은 밴드에만** 쓸 수 있고, 푸시 알림은 기본으로 보내지 않습니다

준비물 3가지: ① 밴드 Access Token ② 아무도 모르는 긴 문자열(MCP_TOKEN) ③ 이 폴더의 `worker.js`

---

## 1단계: 밴드 Access Token 받기
1. **developers.band.us** 에 접속해 밴드 계정으로 로그인합니다
2. **내 서비스 → 서비스 등록**을 누릅니다. 서비스 이름은 아무거나 넣으세요 (예: `claude-band`)
3. 등록한 서비스 화면에서 **Access Token 발급**(또는 "토큰 받기"·"연동") 버튼을 눌러, 내 계정의 Access Token을 받습니다
4. 받은 토큰을 메모장에 잠깐 붙여 둡니다. **이 대화창에는 붙이지 마세요** (비밀번호와 같음)

> 화면 구성이 이 설명과 다르면, **토큰 값을 가리고** 캡처해서 Claude에게 보여 주세요.

## 2단계: MCP_TOKEN 만들기 (커넥터 주소의 비밀번호)
1. 크롬에서 **F12** 키 → 위쪽 **Console** 탭을 누릅니다
2. `crypto.randomUUID()` 를 입력하고 Enter를 누릅니다
3. 따옴표 안의 글자(예: `3f2a...-....`)를 복사해 메모장에 둡니다. 이게 MCP_TOKEN입니다

## 3단계: Cloudflare에 새 Worker 만들기
1. **dash.cloudflare.com** → 왼쪽 **컴퓨트 → Workers 및 Pages** → 오른쪽 위 파란 **애플리케이션 생성**
2. **Worker** 선택 → "Hello World" 시작 템플릿 선택
3. 이름 칸에 **`band-mcp`** 입력 → **배포**
4. 배포가 끝나면 **코드 편집** 버튼을 누릅니다
5. 왼쪽 코드 화면을 클릭 → **`Ctrl+A`**(전체 선택) → **`Delete`**(지우기)
6. GitHub에서 이 폴더의 `worker.js` → 오른쪽 위 **Raw** 버튼 → 화면 클릭 → `Ctrl+A` → `Ctrl+C`
7. Cloudflare 코드 화면에 **`Ctrl+V`** → 오른쪽 위 **배포** → 확인 창에서 다시 **배포**

## 4단계: 비밀 값 넣기
`band-mcp` → **설정** 탭 → **변수 및 비밀** → **변수 추가**를 눌러 아래 3개를 넣습니다.

| 유형 | 이름 (그대로) | 값 |
|---|---|---|
| **비밀** | `BAND_ACCESS_TOKEN` | 1단계에서 받은 밴드 토큰 |
| **비밀** | `MCP_TOKEN` | 2단계에서 만든 문자열 |
| **텍스트** | `WRITE_BANDS` | 글쓰기를 허용할 밴드 이름. 예: `정부정책 자료` (여러 개면 쉼표로 구분) |

- 글쓰기를 아예 막으려면 `WRITE_BANDS`를 만들지 않으면 됩니다 (읽기 전용)
- 다 넣고 **배포**를 누릅니다

## 5단계: claude.ai에 연결
1. claude.ai → **설정 → 커넥터 → 사용자 지정 커넥터 추가**
2. 이름: `네이버 밴드`
3. 주소: `https://band-mcp.ha0220.workers.dev/mcp/` 뒤에 **MCP_TOKEN을 그대로 붙임**
   - 예: `https://band-mcp.ha0220.workers.dev/mcp/3f2a....`
4. 추가가 끝나면 도구 목록에서 **`band_write_post`를 "승인 필요"(손바닥 ✋)** 로 둡니다. 글을 올리기 전에 매번 확인을 받게 됩니다

## 6단계: 시험
Claude에게 "**밴드 목록 보여줘**"라고 말해 보세요. 밴드 3개가 나오면 성공입니다.

## 문제가 생기면
| 증상 | 원인 | 해결 |
|---|---|---|
| 커넥터 추가가 실패함 | 주소의 MCP_TOKEN이 Cloudflare 값과 다름 | 4단계 값과 5단계 주소를 다시 맞춤 |
| `BAND_ACCESS_TOKEN이 비어 있습니다` | 비밀 값 이름 오타나 미배포 | 이름을 정확히 쓰고 배포 |
| `밴드 API 오류 (result_code ...)` | 토큰 만료나 오류 | 1단계 토큰을 다시 발급해 교체 |
| `글쓰기가 허용되지 않았습니다` | 안전장치 작동 | `WRITE_BANDS`에 밴드 이름을 추가 |

## 보안
- 밴드 토큰과 MCP_TOKEN은 **절대 채팅이나 캡처에 노출하지 마세요**
- 커넥터 주소 끝에도 MCP_TOKEN이 들어 있으니, 주소 자체를 공유하지 마세요
- 노출됐다고 생각되면 MCP_TOKEN을 새로 만들어 4·5단계를 다시 하세요
