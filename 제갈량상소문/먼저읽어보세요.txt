============================================================
  제갈량 상소문 — 먼저 읽어 보세요  (윈도우 컴퓨터용)
============================================================

■ 이게 뭔가요?
  매일 아침 7시(또는 컴퓨터를 켤 때) "제갈량 상소문" 창이 저절로 뜹니다.
  - 1부: 클로드 코드 활용 조언 (2,000자 이상)
  - 2부: 은퇴·현금흐름·삶의 방향 조언 (3,000자 이상)
  - 3부: 오늘의 한 줄 과제 (3줄)
  인터넷도, 로그인도, 설치 프로그램도 필요 없습니다. 오늘 날짜에 맞는 글이 열립니다.
  (글은 35일 주기로 조합이 바뀝니다.)


■ 1단계. 폴더를 내 컴퓨터에 놓기
  1) 받은 ZIP 파일을 마우스 오른쪽 버튼 → "모두 압축 풀기".
  2) 안에 있는 "제갈량상소문" 폴더를 "문서" 폴더 안으로 옮깁니다.
  3) ★ 한 번 옮긴 뒤에는 폴더를 다시 옮기지 마세요.
     (옮기면 자동 실행이 길을 잃습니다. 옮겼다면 3단계를 다시 하면 됩니다.)


■ 2단계. 창이 잘 뜨는지 눈으로 확인
  1) 폴더 안의  open.bat  을 두 번 클릭합니다.
  2) 상소문 창이 뜨면 성공입니다.
  ※ 파란 "Windows의 PC 보호" 창이 뜨면 → "추가 정보" 클릭 → "실행" 클릭.
     (인터넷에서 받은 파일이라 윈도우가 한 번 물어보는 것입니다.)
  ※ 아무 창도 안 뜨면 sosomun.html 을 두 번 클릭해 보세요. 이건 항상 됩니다.


■ 3단계. 자동 실행 켜기
  1) 폴더 안의  install.bat  을 두 번 클릭합니다.
  2) 검은 창이 뜨고 글자가 지나갑니다. 아래 두 줄이 초록색으로 보이면 성공입니다.
       [완료] 컴퓨터를 켜고 로그인할 때마다 상소문이 열립니다.
       [완료] 매일 오전 7시에 상소문이 열리도록 등록했습니다.
       다음 실행 예정: ○○○○-○○-○○ 오전 7:00:00
  3) 마지막에 상소문 창이 한 번 더 열립니다. 검은 창은 아무 키나 눌러 닫으세요.
  ※ 빨간 [실패] 줄이 보이면 그 줄을 사진 찍어서 클로드에게 보여 주세요.


■ 4단계. 정말 7시에 되는지 확인하는 법 (둘 중 편한 것으로)
  [방법 A — 가장 쉬움]
    내일 아침 7시에 컴퓨터를 켜 둔 채로 기다려 봅니다. 창이 뜨면 성공입니다.
    7시에 컴퓨터가 꺼져 있었다면, 켜서 로그인할 때 뜹니다.

  [방법 B — 지금 바로 확인]
    1) 키보드의 윈도우 키를 누르고 "작업 스케줄러"라고 입력 → 엽니다.
    2) 왼쪽에서 "작업 스케줄러 라이브러리"를 클릭합니다.
    3) 가운데 목록에서  JegalRyangSosomun  을 찾습니다.
    4) 아래쪽 "트리거" 탭에 "매일 오전 7:00"이 보이면 등록된 것입니다.
    5) 그 줄을 마우스 오른쪽 버튼 → "실행"을 누르면 바로 시험해 볼 수 있습니다.
       ※ 상소문은 "하루에 한 번만" 열리게 만들었습니다. 오늘 이미 열렸다면 시험 실행은
         조용히 아무 일도 하지 않습니다. 이때는 폴더 안의 last_shown.txt 파일을 지우고
         다시 "실행"을 누르세요.


■ 안 될 때 확인할 것 (위에서부터 차례로)
  1) 7시에 컴퓨터가 "꺼져" 있었나요?  → 켜고 로그인하면 그때 뜹니다. 정상입니다.
  2) 로그인 화면(비밀번호 입력 화면)에서 멈춰 있었나요?  → 로그인해야 창이 뜹니다.
  3) 폴더를 옮겼나요?  → install.bat 을 다시 두 번 클릭하세요.
  4) 오늘 이미 한 번 떴나요?  → 하루에 한 번만 뜨는 게 정상입니다.
  5) 그래도 안 되면 아래 "손으로 하는 방법"을 쓰세요.


■ 손으로 하는 방법 (install.bat 이 안 될 때, 컴퓨터 켤 때 열기)
  1) open.bat 을 마우스 오른쪽 버튼 → "바로 가기 만들기".
  2) 키보드에서 윈도우 키 + R 을 누르고  shell:startup  을 입력 → 확인.
  3) 열린 폴더에, 방금 만든 "open.bat - 바로 가기"를 끌어다 놓습니다.
  이제 컴퓨터를 켜고 로그인할 때마다 상소문이 뜹니다.


■ 내 정보(숫자) 고치기
  1) profile.js 를 마우스 오른쪽 버튼 → "연결 프로그램" → "메모장".
  2) 숫자만 고칩니다. (돈은 "만원" 단위. 10000 = 1억 원)
     따옴표(")와 쉼표(,)는 지우지 마세요.
  3) 저장(Ctrl+S) → 상소문 창에서 F5 키.
  상소문 속 모든 계산(합계 자산, 필요 수익률, 세후 월 현금흐름 등)이 새 숫자로 바뀝니다.


■ 창 위의 단추

  가− / 가＋ : 글자 작게 / 크게      밤 · 낮 : 배경 바꾸기      인쇄 : 종이로 뽑기
  3부의 네모 칸 : 과제를 하면 눌러 두세요(이 컴퓨터에 기억됩니다).
  "복사" 단추 : 1부의 따라 하기 문장을 복사합니다. 클로드 코드에 붙여 넣으세요.


■ 끄고 싶을 때
  uninstall.bat 을 두 번 클릭합니다. (폴더와 글은 그대로 남습니다.)
