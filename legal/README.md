# 한국 법령 지식베이스 (은퇴·세금·건보·연금·상가)

질문에 답할 때 **국가법령정보센터의 현행 원문을 직접 인용**하려고 만든 자료 모음입니다.

- 요약본: [핵심조문_정리.md](핵심조문_정리.md) — 금융소득·ISA·연금·건보·국민연금·상가임대차·매각세금·상속증여 (조문 번호와 확인 여부 표시)
- 원문: `laws/` (법률·시행령·시행규칙 본문, 표·산식 포함), `annex/` (별표 PDF를 글자로 바꾼 것)
- 수집일: 2026-11-04 / 출처: https://www.law.go.kr

## 사용법

```bash
python3 legal/tools/article.py 소득세법 14          # 제14조
python3 legal/tools/article.py "조세특례제한법" 91의18  # 제91조의18
python3 legal/tools/fetch_law.py "소득세법" "법인세법"   # 최신 원문 다시 받기 / 새 법령 추가
python3 legal/tools/fetch_annex.py "국민건강보험법 시행규칙" 1의2   # 별표 받기
grep -n "종합과세기준금액" legal/laws/*.txt           # 키워드 검색
```
