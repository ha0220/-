# 한국 법체계 개요 — 질문에 답할 때 쓰는 기준

- 기준일: 2026-11-15
- 사용자가 정리한 4단계 체계(헌법 → 법률 → 명령 → 자치법규)와 공법·사법·사회법 구분은 **맞습니다**. 아래는 실제 세금·건보·임대차 질문에 답할 때 필요한 **보충 사항**입니다

## 1. 법의 위계 (위가 아래보다 우선)

| 단계 | 누가 만드나 | 예 | 보충 |
|---|---|---|---|
| **헌법** | 국민투표 | 조세법률주의(§59), 재산권(§23) | 헌법재판소가 위헌으로 결정하면 그 법률 조항은 효력을 잃음 (헌법재판소법 §47) |
| **법률** | 국회 | 소득세법, 상가건물 임대차보호법, 국민건강보험법 | ① 국회 동의를 얻은 조약도 법률과 같은 효력 (헌법 §6①, 통설) ② 대통령의 긴급명령·긴급재정경제명령도 법률 효력 (헌법 §76) |
| **대통령령 (시행령)** | 대통령 (국무회의) | 소득세법 시행령, 건보법 시행령 | 법률이 **위임한 범위 안에서만** 정할 수 있음. 세율표·기준금액이 여기 있는 경우가 많음 (예: 건보료율 7.19%는 시행령 §44) |
| **총리령·부령 (시행규칙)** | 국무총리·장관 | 소득세법 시행규칙, 건보법 시행규칙 | 총리령과 부령은 같은 단계로 보는 것이 통설. 서식과 세부 계산법 (예: 피부양자 소득 기준은 건보법 시행규칙 별표1의2) |
| **행정규칙 (고시·훈령·예규·지침)** | 각 부처·국세청 | 국세청 예규·기본통칙, 보건복지부 고시 | 원칙적으로 행정기관 내부 기준이라 법원을 구속하지 않음. 다만 **법령이 위임한 고시**는 법령처럼 효력이 있음 ('법령보충적 행정규칙'). 실무(세무서·공단)는 예규대로 처리하므로 사실상 중요 |
| **자치법규** | 지방의회(조례), 단체장(규칙) | 진주시 지방세 감면 조례 | 조례가 규칙보다 위. **법령의 범위 안에서만** 정할 수 있음. 재산세 등 일부 지방세는 조례로 세율을 조정할 수 있음 |

**판례와 해석의 위치**
- 한국은 성문법 국가라 판례 자체가 법은 아니지만, **대법원 판례**는 하급심과 행정청 실무에서 사실상 따르는 기준입니다
- **유권해석**(기획재정부·행정안전부 해석, 국세청 질의회신, 법제처 법령해석)은 실무 기준이지만 법원을 구속하지는 않습니다
- 조세심판원 결정은 행정청을 기속합니다 (국세기본법 §80)

## 2. 충돌할 때 어느 법을 적용하나

| 원칙 | 뜻 | 예 |
|---|---|---|
| 상위법 우선 | 시행령이 법률과 어긋나면 법률이 이김 | 위임 범위를 벗어난 시행령 조항은 무효 |
| **특별법 우선** | 같은 사안이면 특별법이 일반법보다 먼저 | 상가 임대차: 상가건물 임대차보호법 > 민법 / 세금 감면: 조세특례제한법 > 소득세법 |
| 신법 우선 | 같은 단계면 나중 법이 먼저 | |
| 법률 불소급 | 새 법은 원칙적으로 시행 후의 일에만 적용 | 세법은 '소급과세 금지' (국세기본법 §18) |

**세법에만 있는 원칙**
- **조세법률주의** (헌법 §59): 세금의 종류와 세율은 법률로 정해야 함 → 세법은 **문구대로 엄격하게** 해석함
- **실질과세** (국세기본법 §14): 명의가 아니라 실제 귀속자와 거래 실질로 과세함
- **신의성실·근거과세** (국세기본법 §15·§16)

## 3. 내용에 따른 구분 (사용자 정리 + 보충)

| 구분 | 다루는 관계 | 예 | 보충 |
|---|---|---|---|
| 공법 | 국가와 국민 | 헌법, 형법, 세법, 행정법 | 세법은 대표적인 공법 → 세무서 처분에 다툼이 있으면 행정 절차로 감 |
| 사법 | 개인과 개인·기업 | 민법, 상법 | 상가 임대차 계약 자체는 사법 관계 |
| 사회법 | 약자 보호를 위해 국가가 개입 | 노동법, 국민건강보험법, 국민연금법 | 상가건물 임대차보호법은 민법의 특별법이면서 임차인 보호라는 사회법 성격도 있음 |
| **절차법** | 다투는 방법 | 민사소송법, 형사소송법 | 세금·건보 다툼에 쓰이는 절차법: **국세기본법**(이의신청·심사청구·심판청구), **지방세기본법**, **행정심판법**, **행정소송법**. 건보료는 공단 이의신청 → 건강보험분쟁조정위원회 |

## 4. 법이 바뀔 때 꼭 보는 4가지 (2026·2027 변경을 설명할 때 핵심)

| 용어 | 뜻 | 어디에 있나 |
|---|---|---|
| **공포일** | 법이 관보에 실린 날 | 법령 머리말 |
| **시행일** | 효력이 생기는 날. 조항별로 다를 수 있음 | 부칙 제1조, 본문의 `[시행일: …]` 표시 |
| **적용례** | 새 규정을 **어느 거래·소득부터** 적용하는지 (예: "2027년 1월 1일 이후 발생하는 소득분부터") | 부칙 |
| **경과조치** | 이미 진행 중인 거래에는 **옛 규정을 계속** 쓴다는 규칙 | 부칙 |
| **일몰(적용기한)** | "2026년 12월 31일까지 가입하는 경우" 같은 기한. 연장하지 않으면 사라짐 | 주로 조세특례제한법 본문 |

## 5. 세법이 바뀌는 1년 주기 (그래서 '2027년 변경'은 12월 말에야 확정됨)

| 시기 | 단계 | 확정 여부 |
|---|---|---|
| 7~8월 | 정부 **세제개편안** 발표 (2026년은 8.3 발표) | 🟡 안 |
| 9월 | 국회 제출 (2026년은 9.3) | 🟡 안 |
| 10~11월 | 국회 기획재정위원회 조세소위원회 심사 | 🟡 수정 가능 |
| **12월 초** | **국회 본회의 의결** (예산부수법안) | ✅ 법률 확정 |
| 12월 말 | 공포 → 대부분 다음 해 1월 1일 시행 | ✅ |
| 다음 해 1~2월 | **시행령** 입법예고 → 공포 (2026년엔 소득세법 시행령 2025.12.30, 조특법 시행령 2026.2.27 개정이 확인됨) | ✅ 세부 기준 확정 |
| 3월 | 시행규칙 개정 (서식 등) | ✅ |

→ **2026-11-15 현재 '2027년 세법 변경'은 대부분 아직 국회 심의 중인 안**입니다. 이미 법으로 확정된 2027년 변경과는 반드시 구분해서 설명합니다 (`변경사항_2026_2027.md` 참고)

## 6. 이 지식베이스에서 답하는 방식
1. 질문에 해당하는 **법률 → 시행령 → 시행규칙·별표** 순으로 원문 조문을 찾음 (`legal/laws`, `legal/annex`)
2. 답하기 전에 해당 법령을 다시 받아 **시행일이 바뀌었는지** 확인 (`tools/fetch_law.py`)
3. 원문으로 확인한 것(✅), 해석·추정(⚠️), 국회 심의 중인 안(🟡)을 구분하고 기준일을 적음
4. 예규·판례가 필요하면 네이버 검색 커넥터로 실무 자료를 보충하고, **2차 자료라는 점을 밝힘**
5. 큰 금액을 결정하기 전에는 세무사·공단·지자체에 최종 확인을 권함
